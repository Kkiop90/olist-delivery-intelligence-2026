## 2. Explanation of the code

### A. Importing libraries

```python
import pandas as pd
from pathlib import Path as path
```

**What does this mean?**

- `pandas`: A Python library used for data analysis and manipulation.
- `pd`: Short name (alias) for Pandas.
- `Path`: A Python tool used to work with file and folder paths.
- `as path`: Gives `Path` a shorter name.

**Why do we use Pandas?**

Because our project contains CSV files, and Pandas makes it easy to read and analyse tabular data.

### B. Locating the project directory

```python
BASE_DIR = path(__file__).resolve().parent.parent
```

Let's understand each part:

| Code | Meaning |
|---|---|
| `__file__` | Current Python file location |
| `resolve()` | Gets the complete file path |
| `parent` | Goes one folder up |
| `parent.parent` | Goes two folders up |

**Why do we use it?**

Our Python script is inside the `Notbooks` folder. We need to reach the main project folder.

### C. Locating raw data

```python
DATA_PATH = BASE_DIR / "data" / "raw"
```

This creates the path to the raw data folder.

For example:

`olist_delivery_intelligence/data/raw`

The `/` operator joins folder names to create a path.

### D. Creating a list of CSV files

```python
files = [
    "olist_customers_dataset.csv",
    "olist_geolocation_dataset.csv",
    "olist_order_items_dataset.csv",
    "olist_order_payments_dataset.csv",
    "olist_order_reviews_dataset.csv",
    "olist_orders_dataset.csv",
    "olist_products_dataset.csv",
    "olist_sellers_dataset.csv",
    "product_category_name_translation.csv"
]
```

**What is a list?**

A list stores multiple values in one variable.

Here, we store the names of all nine CSV files.

### E. Creating an empty dictionary

```python
data = {}
```

**What is a dictionary?**

A dictionary stores information in key-value pairs.

Example:

```python
student = {
    "name": "Krish",
    "age": 20
}
```

In our project:
- Key = CSV filename.
- Value = Loaded DataFrame.

This allows us to access individual datasets using their filenames.

### F. Loading all datasets using a loop

```python
for filename in files:
    data[filename] = pd.read_csv(datapath / filename)
```

Let's understand this:

| Code | Meaning |
|---|---|
| `for` | Repeats an action |
| `filename` | Current filename |
| `in files` | Takes filenames from the list |
| `pd.read_csv()` | Reads a CSV file |
| `data[filename]` | Stores the dataset in the dictionary |

**Why use a loop?**

Instead of writing nine separate `read_csv()` commands, we use one loop to load all nine files automatically.

### G. Checking dataset information

```python
print("Dataset:", filename)
print("Shape:", data[filename].shape)
print("Columns:", data[filename].columns.tolist())
print(data[filename].head())
```

We use four commands:

| Command | Purpose |
|---|---|
| `print()` | Displays information |
| `.shape` | Shows rows and columns |
| `.columns.tolist()` | Displays column names as a list |
| `.head()` | Displays first five records |

### H. Separating dataset outputs

```python
print("\n" + "=" * 50)
```

This prints a separator line between datasets.

It makes the output easier to read.

## 6. Small code correction

You created:

```python
DATA_PATH = BASE_DIR / "data" / "raw"
datapath = path("data/raw")
```

You should use `DATA_PATH` in your loop instead of `datapath`.

Why? Because `DATA_PATH` uses the project location, while `datapath` is a relative path that depends on the current working directory.

Use:

```python
data[filename] = pd.read_csv(DATA_PATH / filename)
```

Also, your separator can be written as:

```python
print("\n" + "=" * 50)
```
