## 3. Missing Values

```python
print("Missing values:")
print(data[filename].isnull().sum())
```

**Meaning:** Checks how many empty or missing values exist in each column.

- `isnull()` identifies missing values.
- `sum()` counts them column by column.

Example:

| Column | Missing values |
|---|---:|
| customer_id | 0 |
| customer_city | 0 |
| customer_state | 0 |

If a column shows `0`, it has no missing values.

If it shows `100`, that column has 100 missing values.

**Why is this important?**

Missing data can affect calculations and analysis. We need to investigate missing values before deciding whether to remove or fill them.

## 4. Duplicate Records

```python
print("Duplicated values:")
print(data[filename].duplicated().sum())
```

**Meaning:** Checks how many completely duplicated rows exist in the dataset.

- `duplicated()` identifies repeated rows.
- `sum()` counts the duplicate rows.

Example:

| Dataset | Duplicate rows |
|---|---:|
| Customers | 0 |
| Orders | 5 |
| Products | 2 |

**Why is this important?**

Duplicate records can cause incorrect counts and calculations.

Note: This checks completely duplicated rows, not repeated values in individual columns. For example, repeated `order_id` values in an order-items dataset may be valid.

## 5. Data Types

```python
print("Data types:")
print(data[filename].dtypes)
```

**Meaning:** Shows the data type of every column.

Common Pandas data types:

| Data type | Meaning | Example |
|---|---|---|
| `int64` | Whole numbers | 100, 250 |
| `float64` | Decimal numbers | 99.50 |
| `object` | Usually text | Mumbai |
| `datetime64` | Date and time | 2026-11-11 |
| `bool` | True or False | True |

**Why is this important?**

Data types help us understand how to work with each column.

For example:
- Dates should be converted into datetime format.
- Prices should be numeric.
- City names should be treated as text.

## 6. Corrected Code

There are two small corrections in your code:

1. Use `DATA_PATH` instead of `datapath`.
2. Use `"\n"` instead of `"n/"` to print a new line.

```python
import pandas as pd
from pathlib import Path as path

BASE_DIR = path(__file__).resolve().parent.parent
DATA_PATH = BASE_DIR / "data" / "raw"

files = [
    "olist_customers_dataset.csv",
    "olist_geolocation_dataset.csv",
    "olist_order_items_dataset.csv",
    "olist_order_payments_dataset.csv",
    "olist_order_reviews_dataset.csv",
    "olist_orders_dataset.csv",
    "olist_products_dataset.csv",
    "olist_sellers_dataset.csv",
    "product_category_name_translation.csv"
]

data = {}

for filename in files:
    data[filename] = pd.read_csv(DATA_PATH / filename)

    print("\n" + "=" * 50)
    print(f"Dataset: {filename}")

    print("\nMissing values:")
    print(data[filename].isnull().sum())

    print("\nDuplicated values:")
    print(data[filename].duplicated().sum())

    print("\nData types:")
    print(data[filename].dtypes)
```
